# Synapse

Synapse is a Flutter project currently under development.

## Project Setup
1. Install [Flutter](https://docs.flutter.dev/get-started/install).
2. Clone this repository.
3. Run `flutter pub get` in the project root.
4. Start the app with `flutter run`.

## Directory Layout
- `lib/` → main Flutter source code
- `docs/` → project documentation
  - `README.md` → project overview (this file)
  - `BACKLOG.md` → features and ideas list
- `android/`, `ios/`, `windows/`, `linux/`, `macos/` → platform builds

## Current Status
- Bottom navigation works across screens.
- Screens: Dashboard, Camera, Upload Queue, Search Hub.
- Theme: dark mode color scheme.
